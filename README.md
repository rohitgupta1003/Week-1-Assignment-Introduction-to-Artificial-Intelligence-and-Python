# Week 1 – Introduction to Artificial Intelligence & Python

Internship Assignment | Duration: 7 Days | Marks: 100

This repo contains all deliverables for the Week 1 assignment, covering AI fundamentals, Python environment setup, Python basics for AI, an AI case study, and a mini rule-based chatbot project.

## Task 1 – Introduction to Artificial Intelligence (20 Marks)

A short report covering:
- What is AI
- Types of AI (ANI, AGI, ASI)
- AI vs Machine Learning vs Deep Learning
- Real-life applications of AI
- Advantages and limitations

📄 File: `Task1_Introduction_to_AI.pdf`

## Task 2 – Setting Up the AI Development Environment (20 Marks)

Installed and configured Python, VS Code, Jupyter Notebook, and NumPy/Pandas. Wrote a simple program to confirm the setup works.

📄 Files:
- `Task2_Environment_Setup_Guide.pdf` – install steps + screenshots
- `Task2_welcome_program.py` – prints `Welcome to Artificial Intelligence`

Run it with:
```bash
python Task2_welcome_program.py
```

## Task 3 – Python for AI (20 Marks)

Covers variables, data types, user input, and operators using an AI-style example — a simple pass/fail predictor based on marks, plus a bonus temperature converter.

📄 File: `Task3_python_for_ai.py`

Run it with:
```bash
python Task3_python_for_ai.py
```

## Task 4 – AI Case Study: ChatGPT (20 Marks)

A ~450-word case study explaining how ChatGPT works — input, processing, output, and benefits.

📄 File: `Task4_Case_Study_ChatGPT.pdf`

## Task 5 – Mini AI Project: Rule-Based Chatbot (20 Marks)

A simple chatbot built using if-elif statements (no ML involved). Responds to greetings, basic questions, and goodbyes.

📄 File: `Task5_rule_based_chatbot.py`

Run it with:
```bash
python Task5_rule_based_chatbot.py
```

Example:
```
Bot: Hi! I'm a rule-based chatbot. Type 'bye' to exit.
You: hello
Bot: Hello! Welcome.
You: bye
Bot: Goodbye!
```
